# Release v2026.618.0

**Release Date:** June 18, 2026

Release v2026.618.0 adds pipelines, named MCP gateways, a skills store, a task watchdog, an updated apps UX, and security hardening. 

## Pipelines

- **Cases & break-into-pieces automation**: Split complex workflows into distinct cases. [Pipelines reference](/docs/features/pipelines)

## Integrations / MCP

- **Named MCP Gateways & scoped credential governance**: Configure gateways with granular credential access. [Named MCP Gateways reference](/docs/features/mcp-gateways)

## Skills

- **Skills Store**: Manage skills with CRUD operations, versioning, revisions, and file content. [Skills Store reference](/docs/features/skills-store)

## Reliability

- **Task Watchdog**: Monitor liveness and automatically recover background tasks. [Task Watchdog reference](/docs/features/task-watchdog)

## UX

- **Humanized Tools & Access (Apps) UX**: Use the updated interface for tool execution and application access. [Apps UX reference](/docs/features/apps-ux)

## Security

- **Security & isolation hardening bundle**: Apply the new workload isolation and system security baselines. [Security reference](/docs/features/security-hardening)
